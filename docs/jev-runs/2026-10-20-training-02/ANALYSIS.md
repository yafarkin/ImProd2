# Первый полный прогон JEV на обучающей цепочке

20 октября 2026 года один бот Nimble прошёл все 98 ходов на `training-1-sector.json`
с сессионными настройками `main.json`. Код эксперимента взят из коммита `d6f86ed`
ветки `experiment/jev-bots`. Состав вариантов и параметры бота по ходу партии не менялись.

## Результат

| Показатель | JEV, Nimble 9B Q8_0 | SimpleBot, контрольный запуск |
|---|---:|---:|
| Ходов | 98 | 98 |
| Итоговый баланс | −17 874,67 | +83 298, округлено в трассировке |
| Score | −10 440,38 | 135 506, округлено в трассировке |
| Верхний построенный передел | Агломерат и кокс, уровень 1 | `steel-structure` |
| Разблокированное поколение JEV | 1 | См. трассировку |

Идеальный зал на той же конфигурации даёт X(98) = 151 224.
Контрольный запуск SimpleBot использует `leverage=1`, `profile=0`, одну команду
и включённое обслуживание фабрик. В инструменте trace используется seed 2,
в JEV использован seed 42. Это сравнение двух прогонов, а не серия парных опытов
с одинаковой случайностью. У SimpleBot также другой набор способов управления,
включая R&D фабрик. По одному прогону нельзя отделить качество модели
от качества предоставленных ей вариантов и описания последствий.

JEV построил шесть фабрик на первом ходу и назначил им по 10 рабочих.
Дальнейших построек не было. Суммарный выпуск содержит только уголь, руду,
известняк, лом, кокс и агломерат. Чугун, сталь и верхний продукт не выпускались.
Критерии успешного эксперимента не выполнены.

## Решения и задержка

Всего записано 374 запроса. Исполнены 277 команд без ошибок, ещё 97 решений
завершили ход. На первом ходу бот использовал весь предел из 12 действий
без отдельной команды завершения.

| Решение | Число |
|---|---:|
| Постройка | 6 |
| Численность рабочих | 6 |
| Продажа системе | 263 |
| Ремонт | 2 |
| Завершение решений | 97 |
| Исследование поколений | 0 |

Варианты ненулевого исследования присутствовали во всех 374 запросах.
Модель их ни разу не выбрала. Она запросила два ремонта на ходу 26,
но затем оставалась на исходном составе фабрик до конца.

Медиана времени запроса с исполнением составила 1,534 секунды,
95-й процентиль 2,547 секунды, максимум 15,563 секунды.
Сумма времени всех решений составляет 654,93 секунды, около 10,9 минуты.
Это время запросов и исполнения, а не отдельный замер полного процесса.
Ошибок HTTP, неверных ответов и доменных отказов не было.
Хеш-цепочка игрового журнала прошла проверку.

Сервер использовал Ollama 0.40.6 и обновлённую `nimble:latest`,
9B Q8_0, digest `6aa3fde96874d5d9f03306e795016e232610aaa5f19efcb107bf9311c712ccd9`.
По `/api/ps` модель занимала около 10 ГБ видеопамяти, контекст равнялся 8194.
Максимальный зарегистрированный вход составил 7324 токена.

## Вывод и следующий вопрос

Выбор готовых действий устранил прежние ошибки с отсутствующими аргументами.
Интеграция прошла полную партию, но стратегия не достигла развития цепочки
и положительного баланса. Ускорение ответов само по себе эту задачу не решило.

Следующая возможная проверка состоит в выборе между планами развития,
например исследованием и постройкой следующего передела, с явными затратами
и ожидаемым выпуском. Этот прогон такого изменения не проверяет.
Изменять подход и запускать новые партии следует отдельным блоком.

## Материалы и повторение

`settings.json` сохраняет параметры опыта, `result.json` итог,
`metrics.jsonl` состояние по ходам, `statistics.json` подсчитанные показатели,
`server-models.json` сведения о загруженной модели.
Файлы `decisions.jsonl.gz` и `journal.jsonl.gz` сохраняют полные решения
и игровой журнал без потерь. Две трассировки контрольного запуска также сжаты gzip.
Исходники остались в `_bots_llm/jev-training-02/`.

Партия JEV запускается из корня репозитория:

```sh
dotnet src/Game.Bots.Llm.Console/bin/Debug/net8.0/Game.Bots.Llm.Console.dll --jev tools/jev/training.json
```

Для повторения нужно указать новый пустой `OutputDirectory`.
Битовая воспроизводимость ответа модели не гарантируется.
Восстановление игрового состояния из событий не требует обращения к модели.

Контрольный запуск выполнялся так:

```sh
dotnet src/Game.Balancing/bin/Debug/net8.0/Game.Balancing.dll \
  --mode trace \
  --config src/Game.Config/Samples/production-models/training-1-sector.json \
  --session src/Game.Config/Samples/sessions/main.json \
  --teams-per-sector 1 --leverage 1 --profile 0 \
  --out _bots_llm/jev-training-02/baseline.json
```

Режим trace создаёт файлы `bot-trace.txt` и `idealhall-trace.txt` рядом
с указанным путём. Сам `baseline.json` этот режим не создаёт.
