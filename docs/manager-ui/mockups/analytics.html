1.00 — нейтральный уровень. Индекс меняет только сторону спроса: при 1.03 тот же склад продаётся примерно на 3 % дороже, а расходы остаются прежними. Цены по контрактам между командами индекс не трогает — о них вы договариваетесь сами. Куда индекс пойдёт дальше, график не показывает: об этом заранее предупреждает лента новостей.

Множители в таблице считаются из текущего индекса — игрок видит не абстрактное «1.03 ↑», а что именно это значит для его денег. Формулы из docs/external-economy.md §2.1.
