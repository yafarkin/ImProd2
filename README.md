# Производственные цепочки

Офлайн бизнес-симуляция для тимбилдинга и вузов. 6-8 команд по 2-3 человека в одном зале, локальный
Wi-Fi, сервер на Raspberry Pi (или любой машине рядом), клиенты — смартфоны в браузере, большой
экран — проектор. Команды строят производственные цепочки (сырьё → переделы → флагманский продукт),
специализированы по секторам и вынуждены торговать друг с другом. Сервер считает экономику;
переговоры и заключение сделок происходят вживую — люди физически перемещаются по залу и фиксируют
договорённости на бумажных бланках.

Технически: .NET 8, Blazor Server, event sourcing с хеш-цепочкой журнала, вся игровая конфигурация —
данные (JSON), не код. Работает полностью офлайн, без внешних зависимостей.

## Структура решения

```
src/
  Game.Domain/      доменные сущности и правила, без инфраструктуры
  Game.Engine/       движок: журнал событий, расчёт тика, команды
  Game.Config/       загрузка и валидация GameConfig (JSON)
  Game.Persistence/  durable-журнал на диске (append-only + снапшоты)
  Game.Web/          Blazor Server UI, real-time слой, админка
  Game.Bots/         простые боты для симуляции партий
  Game.Balancing/    консольный инструмент калибровки коэффициентов
  Game.LoadTest/     консольный инструмент локальной нагрузочной проверки
tests/               по тестовому проекту на каждый src-проект (кроме Game.Balancing/Game.LoadTest)
docs/                документация проекта
```

## Сборка, тесты, запуск

```
dotnet build ImProd.sln
dotnet test ImProd.sln
dotnet run --project src/Game.Web
```

По умолчанию сервер поднимается на `http://localhost:5180`. Код входа администратора для первой
настройки сессии печатается в консоль при старте (`Код администратора (настройка сессии, только до
старта): ...`) — по нему заходят на `/admin`, там же настраивается сессия и регистрируются участники.

Вспомогательные консольные инструменты — запускаются отдельно, вручную, не участвуют в `dotnet test`:

```
dotnet run --project src/Game.Balancing   # калибровка: много партий ботов, сводный отчёт + CSV
dotnet run --project src/Game.LoadTest    # локальная нагрузочная проверка (см. docs/PILOT_CHECKLIST.md)
```
